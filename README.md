# Blizzard Salary: Location and Pay

**Class:** UCR STAT 107
**Due date:** July 28, 2026
**Name:** Marita Vincent (working solo)

## Description

This project uses survey data from the Blizzard Entertainment salaries to ask whether office location predicts annualized
salary. We compare salaries across the four offices (Irvine, Austin, Cork, and Versailles) using a log-linear regression model, using the  2020 employee reporting on pay disparities at the company. In addition there is a model to show where pay is highest to lowest, color-coded, and displayed on a United States map.

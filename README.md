# Blizzard Salary: Location and Pay

**Class:** UCR STAT 107
**Due date:** July 28, 2026
**Name:** Marita Vincent

## Description

This project uses survey data from Blizzard Entertainment employees to ask whether average annual salary differs across the company's office
locations. We compare salaries across four offices (Irvine, Austin, Cork, and Versailles) using a one-way ANOVA (fit as a linear regression), motivated by 2020 employee reporting on pay disparities at the company. The project also includes a map showing where pay is highest to lowest across these locations, color-coded by mean salary.
